# Morse Code Encoder and Decoder with Audio Playback

Консольное приложение на языке C#, предназначенное для автоматического кодирования текста в азбуку Морзе и обратного декодирования. Программа поддерживает воспроизведение закодированного сообщения с помощью системных звуковых сигналов.

## Постановка задачи и прикладная проблема

Основная прикладная проблема, которую решает данный проект — это **моделирование каналов связи и систем передачи данных со строгими ограничениями на пропускную способность**. 

В реальной инженерной практике (авиация, морская навигация, радиосвязь в условиях сильных помех, а также доступная среда для людей с ограниченными возможностями) азбука Морзе остается эталонным способом передачи информации, так как текстовый сигнал преобразуется в бинарный формат (звук/тишина, свет/тьма).

С точки зрения разработки программного обеспечения, проект решает следующие прикладные задачи:
* **Синхронизация потоков ввода-вывода:** управление системным таймером при воспроизведении звуковых частот (`Console.Beep`) без потери структуры передаваемого сообщения.
* **Стриминговый парсинг данных:** корректная обработка и разделение последовательностей символов на основе временных интервалов (пауз), имитирующих реальные физические протоколы связи.
* **Архитектурная гибкость:** изоляция логики трансляции от логики вывода данных, что позволяет переносить ядро программы на любые UI-платформы (WPF, Web, мобильные приложения) без переписывания алгоритмов.

## Архитектурные паттерны

Для предотвращения связности кода (спагетти-кода) и обеспечения простоты отладки в проекте применены следующие шаблоны проектирования:
1. **Стратегия (Strategy):** Воспроизведение звука вынесено в отдельный интерфейс `IMorsePlayer`. Это позволяет легко заменить системный динамик на визуальное мигание или запись в аудиофайл.
2. **Фасад (Facade):** Класс `MorseFacade` инкапсулирует сложную логику взаимодействия переводчика строк и аудио-плеера, предоставляя главному циклу программы простой интерфейс работы «в один клик».
3. **Репозиторий данных (Data Repository):** Алфавит вынесен в статический класс `MorseAlphabet`. Обратный словарь для дешифратора генерируется автоматически на лету с помощью LINQ, исключая человеческий фактор при заполнении таблиц.

## Логика разделения сигналов

Программа строго следует международному стандарту таймингов азбуки Морзе:
* Буквы разделяются **одним пробелом** (в аудио-эквиваленте — пауза в 3 единицы времени).
* Слова разделяются **тремя пробелами** (в аудио-эквиваленте — пауза в 7 единиц времени).
